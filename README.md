# 한국투자신탁운용 서포터즈 게시물 메이커

사진과 설명을 넣으면 한국투자신탁운용 브랜드 디자인이 자동으로 입혀진
인스타그램 게시물(1080×1350 PNG)이 나오는 도구입니다.

## 사용 방법 — 두 가지 형태

| 형태 | 위치 | 특징 |
|---|---|---|
| **웹사이트** | https://claude.ai/code/artifact/0df6ad28-55e9-4470-8a9b-f8b33a22a307 | 어디서든 접속(기본 비공개). 폰에서도 열림 |
| **로컬 프로그램** | `generator/index.html` 더블클릭 | 설치·인터넷 불필요, 오프라인 완전 동작 |

> PNG 내보내기는 **데스크톱 크롬/엣지** 사용을 권장합니다.

## 게시물 만들기

1. 좌측 하단 버튼으로 슬라이드 추가 — **표지 / 사진 / 텍스트 / 마무리** 4종
2. **사진 슬라이드**: 사진을 끌어다 놓고 제목·설명 입력
   - 미리보기에서 사진을 **드래그**해 위치 조정, 슬라이더로 확대
   - 사진을 안 올리면 자동으로 **설명 전용 레이아웃**으로 전환됨
3. 제목에 `**단어**` 로 감싸면 파란색 강조
4. **전체 PNG 내보내기** → 다운로드 폴더에 슬라이드별 PNG 저장 → 인스타 업로드
5. **프로젝트 저장**을 눌러두면 사진+글+테마가 .json 하나에 담김 (다음에 "프로젝트 열기"로 복원)

- **테마 내보내기**로 현재 컨셉을 JSON 파일로 보관 → 언제든 **테마 가져오기**로 복원
- 프리셋을 바꿔도 입력한 사진·글은 그대로 유지됨

## 준수사항 시스템 (서포터즈 교육자료 반영)

- 우측 패널에서 **콘텐츠 유형**을 고르면 그 유형의 필수 문구가 마무리 슬라이드에 자동 삽입됩니다:
  - 단순 홍보·밈 / 금융 개념 소개 / 활동 후기 / **채널 홍보·이벤트·시청 후기(광고 해당 — 필수 기재 문구 전문+심사필)** / 임직원 출연
- 광고성 필수 문구 전문이 들어가면 마무리 장 레이아웃이 자동 조정됩니다
- **PNG 내보내기 시 자동 검사**: 상품명 의심 표현(ACE ○○○), 종목코드, 수익률·% 표기, 필수 문구 누락을 경고
- "제작 체크리스트 보기" 버튼으로 전체 규정 확인 — 상세는 [content-guidelines.md](brand/content-guidelines.md)
- ⚠ 심사필 번호(제00-000호)는 자리표시자 — 운영국에서 실제 번호를 받아 교체하세요. 모든 콘텐츠는 게재 전 운영국 심의 필수.

## 피그마 왕복 워크플로우 (피그마 → 사이트 → 피그마)

앱의 **"피그마 연동"** 섹션에 왕복에 필요한 도구가 모여 있습니다:

- **피그마 편집용 SVG (전체/현재)** — 완성한 슬라이드를 SVG로 내보내 피그마 캔버스에 끌어다 놓으면 텍스트·도형이 **편집 가능한 레이어**로 들어갑니다 (피그마에 Pretendard 폰트 필요 — 로컬 폰트 설치 시 자동 인식). 픽셀 정확한 업로드용은 PNG, 피그마 수정용은 SVG.
- **템플릿 가이드** — 앱의 텍스트존·사진존 위치가 표시된 1080×1350 밑그림 SVG. 피그마에서 이걸 깔고 템플릿을 디자인하면 앱과 정확히 맞습니다.
- **텍스트 복사** — 전체 슬라이드 텍스트를 클립보드로 (피그마 재편집·인스타 캡션용).
- **텍스트 조정 슬라이더** (슬라이드 편집 패널) — 텍스트 크기(70~140%)는 모든 슬라이드에서, 템플릿 배경을 쓰는 슬라이드는 **세로 위치(±320px)·오버레이 텍스트 컬러**까지 조정 가능. 피그마 템플릿과 텍스트가 어긋나면 슬라이더로 맞추세요.

**1단계 — 피그마에서 기본 구조 설계**
- 피그마에서 **1080×1350 프레임**으로 템플릿 디자인 (배경, 장식, 고정 그래픽)
- 사진이 들어갈 자리는 **투명하게 비워두기** (구멍 뚫기)
- 프레임 선택 → Export → **SVG 또는 PNG(2x)** 로 내보내기

**2단계 — 사이트에서 초안 생성**
- 게시물 메이커에서 슬라이드 선택 → **"피그마 템플릿 배경"** 에 내보낸 파일을 끌어다 놓기
- 템플릿이 배경으로 깔리고, 업로드한 사진은 투명 영역 뒤로 비침
- 제목·설명 입력 (비운 칸은 표시 안 됨) → PNG 초안 내보내기

**3단계 — 피그마로 돌아가 수정·보완**
- 방법 A: 내보낸 PNG를 피그마 프레임에 깔고 위에서 세부 수정
- 방법 B: 무료 플러그인 **html.to.design**으로 `templates/html/slide1~4.html`을 임포트
  → 모든 텍스트·도형이 편집 가능한 피그마 레이어로 들어옴
- 공식 로고 벡터: `brand/logo_korea_bk.svg`(블랙)·`_wh`(화이트)·`_blue`(블루) — 피그마에 드래그하면 벡터 임포트

## 고급: 렌더 모드 (헤드리스 캡처용)

앱 URL에 `?preset=테마&sel=슬라이드번호&render=1` 을 붙이면 UI 없이 해당 슬라이드만 1080×1350 원본 크기로 표시됩니다. Chrome headless와 조합하면 픽셀 정확한 PNG를 스크립트로 뽑을 수 있습니다.

## 고급: 템플릿 HTML을 픽셀 그대로 PNG로 렌더

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --force-device-scale-factor=1 \
  --screenshot="out.png" --window-size=1080,1350 --hide-scrollbars \
  "file://$(pwd)/templates/html/slide1.html"
```
