테마 JSON을 저장해두면 언제든 같은 컨셉을 다시 불러올 수 있습니다. 프리셋을 바꿔도 입력한 사진·글은 유지됩니다.

내보내기

PNG는 인스타 업로드용 완성본입니다. 프로젝트 파일(.json)에는 사진·글·테마가 모두 담깁니다.

피그마 연동

SVG를 피그마 캔버스에 끌어다 놓으면 텍스트·도형이 편집 가능한 레이어로 들어갑니다 (Pretendard 폰트 설치 필요). "템플릿 가이드"는 피그마에서 템플릿을 디자인할 때 텍스트존 위치를 알려주는 밑그림입니다. 픽셀 정확한 완성본은 PNG를 사용하세요.

제작 체크리스트

ACE ETF 서포터즈 콘텐츠 교육 자료 기준

공통 (모든 콘텐츠)
  • 내부 심의 절차 준수 — 운영국의 심의 완료 회신 없이 게재 불가. 업로드 이후에도 수정 요청이 있을 수 있음
  • 상품명 노출 불가 — 임직원이 출연하지 않는 콘텐츠에서는 구체적 상품명 언급 불가 (사진 속 노출·화면 캡처도 불가)
  • 임직원 미출연 콘텐츠는 ACE ETF 브랜드만 노출
  • 당사 로고를 쓰는 금융정보 콘텐츠에는 서포터즈 로고 또는 'ACE ETF 서포터즈' 문구를 함께 기재 (공식 콘텐츠와 구분)
  • 비속어·타인에게 불쾌감을 줄 수 있는 표현 금지
유형별
  • 단순 홍보·밈 — 자유 제작 가능
  • 금융 개념 소개 — 개념 소개까지만. 상품 추천·특정 불가
  • 활동 후기 — 서포터즈 기간 중 활동·마무리 후기 가능
  • 채널 홍보 / 이벤트 참여·시청 후기 — '영위업무/이용후기 광고'에 해당 → 필수 기재 문구 전문 + 심사필 번호 삽입. 이벤트명에 상품명이 들어가면 후기 제작 불가 (예: "ACE KRX금현물 ETF 매수 이벤트 후기" 불가 / "ACE RUN 참여 후기" 가능)
  • 임직원 출연 — 상품명 언급 가능하지만 협회 심의 필요 (영상은 스크립트→영상물 2단계 심의, 일정 여유 필수). 상품 언급 시 실적배당·원금손실 문구, 위험등급·수수료·총보수 기재, 수익률 표기 시 BM 병기·기간 요건(3년 미만: 6개월+1년 / 3년 이상: 1년+3년+설정일 이후) 확인
이벤트 경품
  • 서포터즈 계정에서 서포터즈가 직접 구매·발송 불가 — 이벤트 진행·경품 발송은 사전 문의 필수
심사필 번호
  • 필수 문구 속 "제00-000호(0000.00.00~0000.00.00)"는 자리표시자 — 운영국에서 실제 번호를 받아 교체할 것
